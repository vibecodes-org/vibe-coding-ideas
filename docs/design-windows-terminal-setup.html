In-browser terminal on Windows: the one-time setup screen

Same panel, same three steps, same buttons as the Mac version today. Only the words that have to change for Windows change. The Windows version appears to anyone opening a board on a Windows PC; the Mac version is untouched.

Text with a dashed blue outline differs from the Mac screen. Each difference is listed under "Decisions" below.

Decisions for Nick on this screen

  • Step 2 is a new sentence (“Open the file to install VibeCodes”), because there is no drag-to-Applications on Windows. Recommended.
  • Step 2 gains a yellow note about the blue Windows warning while the app is unsigned. Recommended: hiding it would leave people stuck at a scary screen.
  • “Windows on ARM?” link mirrors the Mac’s “Intel Mac?” link. Recommended, for parity.
  • Step 1 drops “Apple-notarized” for Windows and says “signed” only once the certificate is in.
