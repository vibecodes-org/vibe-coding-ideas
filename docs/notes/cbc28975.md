# Card cbc28975: first-run setup panel cut off in a short terminal

## Root cause
The first-run overlay in `src/components/board/terminal-session-view.tsx` (the
`absolute inset-0 flex flex-col items-center justify-center overflow-y-auto`
div) centres its content with plain `justify-center`. When the content is taller
than the box, centring pushes the overflow equally off the top and bottom; the
part above the top edge can never be scrolled to. Short window = clipped panel.
Same on Mac and Windows (shared overlay, not Windows-specific).

## Same cause elsewhere
`terminal-popout-view.tsx`: six overlays with the same classes and no
`overflow-y-auto` at all, so tall panels were simply clipped. Fixed too.

## Fix
`justify-center` -> `justify-center-safe` (Tailwind 4.1 emits
`justify-content: safe center`: centre only when it fits, else start at the top)
and add `overflow-y-auto` to the pop-out overlays.

## Checked
Compiled CSS confirmed to emit `safe center`. Real browser at 375x400: plain
centre put a 900px child at top -250 (unreachable); safe centre at top 0 and
scrollable. Regression test: "the first-run overlay scrolls and only centres
when the content fits" in terminal-session-view.test.tsx (failed before, passes
after). jsdom has no layout, so the test pins the classes.
