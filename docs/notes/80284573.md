# Card 80284573: measured model ignored the helper/session split

## Bug
The measured-model check (mcp-server/src/lib/measured-model.ts, called from tools/workflows.ts on complete_step/fail_step) picked the model with the most output across every row of the usage line. The usage line also holds the coordinating session's own calls, so a Sonnet helper run from an Opus coordinator got a false "wrong model" flag when the coordinator wrote more. Research: 10 of 10 flags checked against logs were false (about 2% of Sonnet steps). It is live since PR #504 (27 Nov 2026).

## Decision (approved by Nick)
Only the helper's own work decides the measured model; the session's own calls still count for cost; with no helper the session's own model decides.

## How
- Usage script (src/lib/step-cost/usage-command.ts, awk): each row now also carries `helper_output_tokens`, the part of its output written by subagent transcripts. Rows stay one per model, so storage, cost and the 12-row limit are unchanged (the field is not stored).
- Validator (src/lib/step-cost/usage-schema.ts): `helper_output_tokens` declared optional, because zod drops undeclared keys silently.
- Rule: if any row has helper output > 0, only helper output counts; otherwise (no helper, or an old line without the field) the old all-rows rule applies.
- Script version: the saved file name is the sha256 prefix of its text, so the changed script gets a new name automatically. The claim's command points at the new name; sessions that only have an older copy fall back to the newest saved one (old behaviour, still correct) until the helper saves the new one on its next launch. The full-command path embeds the new script directly.

## Ruled out
- A share threshold: one false flag had a 93% coordinator share.
- Separate rows per source: would duplicate model rows and hit the 12-row cap / storage shape.
- scripts/step-usage-backfill.mjs left alone: it feeds stored cost only, not the measured-model check.

## Tests
- measured-model.test.ts (helper wins, real wrong-model helper still flagged, no helper, old lines)
- usage-schema.test.ts (field kept)
- usage-command.test.ts (script tags rows)
