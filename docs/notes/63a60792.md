## Facts checked (11 Nov)
- Both makers now publish a one-line installer that needs no Node and no admin rights and installs to `~/.local/bin` (already on the bridge's PATH fallback):
  - Claude Code: `curl -fsSL https://claude.ai/install.sh | bash` (code.claude.com/docs/en/setup)
  - Codex: `curl -fsSL https://chatgpt.com/codex/install.sh | sh` (learn.chatgpt.com/docs/codex/cli; script reads `CODEX_INSTALL_DIR`, default `$HOME/.local/bin`)
- Sign-in status, scriptable: `claude auth status --json` → `loggedIn` true/false (exit 0 either way); `codex login status` → exit 0 signed in, exit 1 "Not logged in". Checked with throwaway config folders, not Nick's.
- Sign-in commands: `claude auth login` prints a URL and "Paste code here if prompted" (works from another computer). `codex login` runs a local callback on 127.0.0.1:1455 (browser must be on the same Mac); `codex login --device-auth` gives a one-time code (works anywhere).
- Unsigned first run of either agent shows its own welcome/sign-in screens in a terminal. Not checked: whether a launch prompt survives that first-run sign-in.
- Install-page addresses: app's Claude link `docs.claude.com/en/docs/claude-code` redirects (302); bridge's Codex link `developers.openai.com/codex/cli/` redirects (308); app's Codex link `learn.chatgpt.com/docs/codex/cli` is live. App and bridge disagree on Codex's.
- `terminal_sessions` has no `ended_reason` column; setup needs no database change.

## Ruled out
- Running installs over the helper's control connection (no visible output, can't take a pasted sign-in code).
- Letting the link carry any command text or URL: the link carries only `setup=install|signin|signin-code`; commands live in the bridge.
- npm / Homebrew installs (need Node or Homebrew; the makers' own one-liners need neither).
- A database column to mark setup sessions: they never record a folder, so they already stay out of Recent.

2. Before-the-click: helper reports signed-in too and can re-check on demand; menus/picker offer "Set up …"; signed-out caught before launch. Helper release.
3. Guide pages and a "board connected?" check, if still wanted.
