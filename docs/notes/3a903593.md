## Readout query (stage 2)

Trial attempts = usage rows after the edit time on steps whose text carries the second-round marker.

```sql
select s.title, count(*) attempts, round(avg(u.calls)) avg_calls
from workflow_step_usage u
join task_workflow_steps s on s.id = u.step_id
where u.idea_id = '62e57071-3645-422f-96c0-b2042e39e6dd'
  and u.created_at >= '<edit time>'
  and s.description ilike '%second or later round%'
  and exists (select 1 from workflow_step_usage p
              where p.step_id = u.step_id and p.created_at < u.created_at)
group by s.title;
```
