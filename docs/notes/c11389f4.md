# Card c11389f4: linked-task-hidden message repeats

## Cause (confirmed by test)
The board keeps `autoOpenTaskId` from a link. It is only cleared after the card's dialog opens and closes. If filters hide the card, the dialog never opens, so the id stays. The effect that shows "The linked task is hidden by current filters" depends on `columns` and `filteredColumns`, so it re-ran (and toasted) on every board change. Introduced with the deep-link work (5064cab / fd34068).

## Fix
Logic moved to `src/components/board/use-hidden-linked-task-notice.ts`: shows the message once per card id (ref), then calls `onShown`, which drops `autoOpenTaskId`. Clear filters restores `autoOpenTaskId` so the card opens once visible.

## Tests
`use-hidden-linked-task-notice.test.tsx`: the repeat-update test showed 6 toasts before the fix, 1 after.

## Decisions
- Dropping the link means later filter changes do not pop the card open (the card's proposal).
- Not covered: a full-board render test; the hook is tested in isolation.
