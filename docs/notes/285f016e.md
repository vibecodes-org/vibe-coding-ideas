Not observed live; read from code only. `NudgeBanner` (`src/components/shared/nudge-banner.tsx`) already uses the safer pattern: hide until mounted, read storage in an effect, wrap in try/catch.
- Facts behind the wording: agents on the tab are the idea's shared team (any team member can assign them; you can only add agents you own). Steps are matched to agents by role automatically (exact, close match, or AI); `setManualRoleMatch` reassigns that role's pending steps when you pick one in Workflow Roles; "Auto-match" undoes it. Agents are created and edited on the /agents page.
- Guide pages: none describe the AI Team tab's layout or either explainer note, so no guide text changes. (The ai-agent-teams guide's "Idea Agent Team" section talks about the idea page's Agents section, which still exists.)

## Decisions (recommended, awaiting Nick)
1. Wording as in the mock.
2. Show the note only when the team has agents; the empty screen already explains. Differs from Workflows (shows when empty).
3. Its own "hidden" memory, per browser, like Workflows. Hiding one never hides the other.
4. Build one shared note component and move the Workflows note onto it (same look, same storage key so existing dismissals stick). Adds a "Dismiss" label for screen readers and the safer load pattern to both.

- Reusing `NudgeBanner`: different look (title, coloured border, action buttons). Would not match the Workflows note.
- Remembering dismissal on the account (database): Workflows note doesn't; would need a migration for a tiny gain.
