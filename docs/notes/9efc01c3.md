# Card 9efc01c3 - helper accepts launch links for any account

## Result
Reproduced at code level (not live): a launch link whose tokens name another account started a bridge and overwrote the saved control credentials. Live two-account check NOT done; owed after the helper release.

## Cause
`terminal/helper/main.js` `handleLaunchUrl` (and `handleOpenTerminalUrl`) checked the link shape and relay host but never the account (`sub`) in the tokens, because the helper holds no signing secret and kept no notion of its own account. The relay's OWNER_MISMATCH only compares the bridge and browser legs with each other. A `helperToken` in a link was also written by `saveControlCredentials` and used by `connectControl`, so a foreign link re-pointed the persisted always-on connection. Open-terminal had the same gap (it saved credentials before the relay ack).

## Decisions
- Owner = the `sub` the helper first paired with, pinned in userData `helper-owner.json`. An existing helper with no pin adopts the `sub` of its saved control credentials (Nick's already-paired Mac is protected with no action).
- Launch links: session token and helperToken must both carry a `sub`, agree, and match the owner. Checked before saving, connecting or forking.
- Open-terminal: checked before the cooldown, save and socket; pinned only after the relay ack.
- Refusal: log plus a Mac notification; nothing forks, nothing saved.
- Legit change of account: new tray item "Sign out this Mac" clears the pin and saved credentials.
- Known limit: a never-paired helper pins the first account whose launch link it sees (trust on first use), since the helper cannot verify signatures. Stronger option (a decision for Nick): pair via a relay-verified step before pinning.
- Not changed: relay, minting route, link contents.

## Ruled out
Link cannot carry a command (`--cmd`/`BRIDGE_CMD` are CLI/env only); permission mode allowlist unchanged.

## Where
Fix: terminal/helper/main.js (loadOwner, ownerAllows, forgetOwner, tray). Tests: terminal/test/helper-owner.test.mjs; control-connection.test.mjs now uses one fixed owner. Needs a notarized helper release plus minimum-version bump.
