Decisions for Nick

  1. When it shows: 3 or more steps in one card's run finished with no cost (recommended). Steps the session deliberately didn't hand to a helper only ever came to 1 or 2 per run, while every run hit by the worktree refusal had 3 or more.
  2. Time span for the board strip: the last 14 days (approved).
  3. Where: both the board strip and the note in the card (recommended), or only one.
  4. Closing the strip: it stays closed until you reload in a new browser session or another card is flagged, same as the setup strip (recommended).
  5. A notification as well: leave it out for now and add it as a second stage if the strip isn't enough (recommended).
