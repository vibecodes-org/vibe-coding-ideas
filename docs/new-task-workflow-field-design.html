New Task: choose the card's workflow before Create

One new field, Workflow, sits under Labels in the New Task dialog. It uses the same kind of dropdown as Assignee. Left alone, it shows which workflow the card's labels will attach, and updates as you pick labels. You can also pick a workflow yourself, or pick "None" for a plain note card. The yellow outline marks the new field. It is not part of the design.

1. Default: nothing touched

The field starts on Automatic. With no labels picked, nothing matches, so it reads "Automatic: none". With the Bug label picked, it reads "Automatic: Bug Fix". Leaving it on Automatic gives the same result as today.

Differences from the fields next to it

  • Decision 1: Workflow has a small grey line under it saying where the choice came from. Assignee and Labels have none. Recommended: keep it, because "Automatic: Bug Fix" alone doesn't say why.
  • Same as Assignee: same dropdown, same size, label above, saves only when you press Create.
  • Hidden when the board has no workflows at all, the same way Labels is hidden when the board has no labels.
  • Not shown: the Title and Description buttons and image area are unchanged and left out of some frames to save space.
